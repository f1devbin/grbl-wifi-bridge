# GRBL Wi-Fi Bridge: GRBL по Wi-Fi для лазерных граверов и ЧПУ-станков (ESP32-S3)

[![Прошивка в браузере](https://img.shields.io/badge/прошить-в%20браузере-blue)](https://f1devbin.github.io/grbl-wifi-bridge/ru/)

[English](README.md) | **Русский**

GRBL Wi-Fi Bridge превращает плату ESP32-S3 в **Wi-Fi адаптер для любого GRBL-станка с USB-портом**: диодных лазерных граверов, фрезеров типа 3018, плоттеров. ESP32-S3 подключается к USB-порту станка вместо компьютера, а управлять станком можно по Wi-Fi из **LightBurn**, **Universal Gcode Sender** и любой GRBL-программы с подключением по TCP / telnet. Станок не нужно переделывать, вскрывать или перепрошивать.

**[Прошить из браузера →](https://f1devbin.github.io/grbl-wifi-bridge/ru/)** (Chrome или Edge на компьютере). Там же настраивается Wi-Fi.

## Возможности

- **USB host на ESP32-S3**: работает напрямую с USB-UART чипом станка. Драйверы для CH340/CH341, CP210x, FTDI и любых CDC-ACM устройств (CH343, контроллеры со встроенным USB).
- **Прозрачный TCP-мост на порту 23**: байты передаются без изменений, поэтому потоковая отправка G-code, команды реального времени (`?`, `!`, `~`, `Ctrl-X`) и настройки GRBL работают так же, как по кабелю.
- **Веб-панель** по адресу `http://grbl-bridge.local/`: состояние, большая кнопка СТОП, пауза и продолжение, консоль GRBL с быстрыми командами (`$I`, `$$`, `$X`, `$H`), настройки, Wi-Fi, обновление прошивки. Английский и русский язык, адаптивная вёрстка для телефона, крупный контрастный текст.
- **Живое состояние GRBL**: когда программа не подключена, мост спрашивает у GRBL статус каждые 2 секунды, поэтому панель и светодиод показывают Idle, Alarm или Run ещё до запуска программы.
- **Безопасность**: если связь с программой рвётся во время работы (пропал Wi-Fi, ноутбук уснул, программа упала), мост отправляет паузу и сброс GRBL. Движение останавливается, лазер или шпиндель выключаются.
- **Три способа настроить Wi-Fi**: со страницы прошивки (Improv), через точку доступа `GRBL-Bridge-setup` или в веб-панели.
- **Обновление по воздуху** с автоматическим откатом, если новая прошивка не запустилась.
- **Светодиод состояния** (WS2812 на GPIO48): цвет показывает Wi-Fi, станок и работу.
- **mDNS**: имя `grbl-bridge.local`, сервисы `_http._tcp` и `_telnet._tcp`.

## Что нужно

- Плата ESP32-S3 со **встроенным USB OTG** (GPIO19/GPIO20) и **flash от 8 МБ**. Проще всего с платами в стиле ESP32-S3-DevKitC-1 с двумя разъёмами USB-C: один идёт через USB-UART чип для питания и прошивки, второй (встроенный USB) подключается к станку.
- 5 В на встроенном USB-порту, чтобы питался USB-чип станка. На многих платах с двумя USB-C для этого нужно запаять перемычку (часто подписана `USB-OTG`), которая соединяет VBUS обоих разъёмов. **Сначала проверьте, не выдаёт ли станок 5 В в свой USB-порт сам**: если выдаёт, перемычку не замыкайте.
- USB-адаптер питания для ESP32-S3, подключённый к её порту USB-UART.

## Быстрый старт

1. Откройте **[страницу прошивки](https://f1devbin.github.io/grbl-wifi-bridge/ru/)**, подключите ESP32-S3 к компьютеру через порт USB-UART и нажмите **Install**.
2. Когда страница предложит, выберите сеть Wi-Fi и введите пароль. После подключения появится ссылка на мост.
3. Отключите плату от компьютера, подайте питание от USB-адаптера и подключите станок к встроенному USB-порту.
4. Откройте `http://grbl-bridge.local/` (или IP-адрес из роутера) и проверьте, что станок подключён и GRBL отвечает на `$I`.
5. Подключите программу:
   - **LightBurn**: Devices → Create Manually → GRBL → Ethernet/TCP → адрес моста, порт 23.
   - **Universal Gcode Sender**: Tools → Options → Sender Options → Connection driver: TCP, затем подключение к адресу моста, порт 23.
   - **Программы, которые умеют только последовательный порт** (Linux, macOS):

     ```bash
     socat pty,link=$HOME/ttyGRBL,raw,echo=0 tcp:grbl-bridge.local:23
     ```

     и выбрать порт `~/ttyGRBL`.

Если Wi-Fi не удалось настроить со страницы прошивки или сохранённая сеть недоступна 30 секунд после включения, мост поднимает точку доступа **`GRBL-Bridge-setup`** (пароль `grblbridge`). Подключитесь к ней, откройте `http://192.168.4.1` и укажите свою сеть. Управлять станком через эту точку доступа нельзя.

## Светодиод

| Цвет | Значение |
|---|---|
| Фиолетовый, мигает | Точка настройки, нет Wi-Fi |
| Красный, мигает | Нет подключения к Wi-Fi |
| Жёлтый | Wi-Fi есть, станок не подключён |
| Зелёный | Готов |
| Синий | Программа подключена по TCP |
| Белый, мигает | Идёт работа (`Run` или `Jog`) |
| Красный, быстро мигает | Тревога GRBL `Alarm` или сработал аварийный стоп |

На некоторых платах светодиод заработает только после замыкания перемычки `RGB`.

## Безопасность

- Аварийный стоп срабатывает, когда программа отключается, а GRBL в состоянии `Run`, `Jog` или `Hold` либо строка G-code отправлялась последние 10 секунд. Команды только для чтения (`$I`, `$$`, `?`) его не взводят, поэтому проверка станка и отключение не сбрасывают простаивающий контроллер. Оборванное соединение определяется по TCP keepalive примерно за 6 секунд. После сброса GRBL теряет позицию, задание придётся запускать заново. Защиту можно отключить в панели.
- Мост не выставляет DTR, поэтому не сбрасывает контроллер при подключении или перезагрузке моста. Сбрасывайте станок его собственной панелью или программой, когда это нужно.
- Wi-Fi надёжнее кабеля не бывает. Для лазера используйте динамическую мощность (`M4`): луч гаснет, когда движение останавливается. Не оставляйте работающий лазер или фрезер без присмотра.
- Мост отказывается перезагружаться, менять Wi-Fi, TCP-порт и скорость порта, пока GRBL сообщает `Run`, `Jog` или `Hold`, а также не принимает прошивку, пока подключена программа или G-code отправлялся последние 10 секунд. Сначала нажмите СТОП: перезагрузка моста во время работы оставила бы станок без программы управления.
- У веб-панели нет пароля: открыть её может любой в вашей локальной сети. Используйте мост только в доверенной сети.

## Подойдёт ли для моего станка?

Мост работает со всем, что говорит на GRBL (или grblHAL) через USB-UART чип: с большинством любительских диодных лазерных граверов, фрезерами типа 3018 и GRBL-плоттерами. Сам TCP-мост прозрачный, поэтому достучаться можно и до других USB-UART устройств (например, 3D-принтеров), но отображение состояния и аварийный стоп рассчитаны на ответы GRBL. Скорость порта по умолчанию 115200, меняется в панели.

Контроллерам, у которых уже есть Wi-Fi (FluidNC, Grbl_ESP32), этот мост не нужен.

## Сборка из исходников

Прошивка собирается на ESP-IDF 6.1 через PlatformIO; драйверы USB host, WS2812 и mDNS подтягиваются из ESP Component Registry (`src/idf_component.yml`).

```bash
pip install platformio
pio run
```

Обновление по Wi-Fi без сброса настроек:

```bash
curl --data-binary @.pio/build/esp32s3/firmware.bin http://grbl-bridge.local/api/update
```

или загрузите `firmware.bin` в веб-панели. Новая прошивка подтверждается после 30 секунд работы; если она упадёт раньше, загрузчик вернёт предыдущую.

`tools/release.sh` собирает заводской образ для страницы прошивки (загрузчик, таблица разделов и приложение) и пересобирает сайт через `tools/build_site.py`.

HTTP API и разметка flash описаны в [README.md](README.md).

## Состояние проекта

Бета. Wi-Fi, веб-панель, настройка через Improv, обновление по воздуху и откат проверены на железе. USB host и TCP-мост проверены на реальном контроллере GRBL 1.0.2 (Elidor Z6, CH340): опрос состояния, `$I` и консоль работают. Движение, лазерные задания и аварийный стоп во время работы ещё предстоит проверить на станке. USB host построен на официальных драйверах Espressif; сообщения о работе с конкретными станками и USB-чипами пишите в [issues](https://github.com/f1devbin/grbl-wifi-bridge/issues).
