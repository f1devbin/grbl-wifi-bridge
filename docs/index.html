Wireless GRBL for laser engravers and CNC

Control your GRBL laser engraver or CNC over Wi-Fi

GRBL Wi-Fi Bridge turns an ESP32-S3 board into a Wi-Fi adapter for any GRBL machine with a USB port. Plug it in where the computer used to be and connect from LightBurn, Universal Gcode Sender or any sender with a TCP connection. Nothing to open, solder or reflash on the machine.

Your browser cannot access USB ports. Open this page in Chrome or Edge on a computer. USB access needs a secure page. Open the https:// address of this page.

Connect the ESP32-S3 to this computer through its USB-UART port, press the button and choose the port. After flashing, enter your Wi-Fi network: the page shows a link to the bridge when it is online.

How it works

1

Flash

Install the firmware from this page and pick your Wi-Fi network. No toolchain, no drivers.

2

Plug in

Power the ESP32-S3 from a USB adapter and connect the machine to its native USB port.

3

Connect

Add the bridge in LightBurn or UGS as a TCP device on port 23 and send jobs as usual.

Features

USB host

Works with the machine's own USB chip: CH340/CH341, CP210x, FTDI and CDC-ACM devices.

Transparent TCP

Port 23 passes bytes unchanged: streaming, real-time commands and $ settings work as over a cable.

Web panel

Status, big STOP button, pause and resume, GRBL console, settings and updates in any browser, on a phone too.

Emergency stop

If the sender disconnects during a job, the bridge sends feed hold and a GRBL reset: motion stops, laser and spindle switch off.

Easy Wi-Fi setup

From this page, from the setup access point or from the web panel. DHCP: reserve the bridge's address in your router.

Safe updates

Over-the-air updates with automatic rollback if a new image does not start.

Connect your software

LightBurn

Devices → Create Manually → GRBL → Ethernet/TCP → bridge address, port 23.

Universal Gcode Sender

Tools → Options → Sender Options → Connection driver: TCP, then connect to the bridge address, port 23.

Serial-only programs

Create a virtual serial port on Linux or macOS:

socat pty,link=$HOME/ttyGRBL,raw,echo=0 \
  tcp::23

What you need

  • An ESP32-S3 board with native USB OTG on GPIO19/GPIO20 and at least 8 MB of flash. Boards in the ESP32-S3-DevKitC-1 style with two USB-C ports are the easiest.
  • 5 V on the native USB port so the machine's USB chip is powered. On many dual-USB-C boards this needs a solder jumper (often marked USB-OTG). Check first that the machine does not drive 5 V on its own USB port.
  • A USB power adapter for the ESP32-S3.
  • Any machine running GRBL or grblHAL with a USB serial port: diode laser engravers, 3018 CNC routers, pen plotters.

FAQ

Does it work with LightBurn over Wi-Fi?

Yes. Add a GRBL device with the Ethernet/TCP connection type, the bridge address and port 23. LightBurn then streams jobs over Wi-Fi exactly as over USB.

Which machines are supported?

Any controller that speaks GRBL or grblHAL through a USB serial chip (CH340, CP210x, FTDI or CDC-ACM): most hobby diode laser engravers, 3018-style CNC routers and GRBL pen plotters. Controllers that already have Wi-Fi, such as FluidNC, do not need it.

Do I have to open or modify the machine?

No. The bridge plugs into the machine's existing USB port. The only soldering may be a jumper on the ESP32-S3 board that powers its USB port.

Why ESP32-S3 and not a regular ESP32?

The bridge acts as a USB host for the machine's USB chip. The classic ESP32, ESP32-C3 and ESP32-C6 have no USB host; the ESP32-S3 does.

What happens if Wi-Fi drops during a job?

When the connection to the sender breaks while GRBL is running, the bridge sends feed hold and a GRBL reset, which stops motion and switches the laser or spindle off. The job has to be restarted.

Is it safe to use on my network?

The web panel has no login, so anyone on your local network can open it. Use the bridge on a trusted home or workshop network and never expose it to the internet.

How do I update the firmware?

Upload the update file in the web panel, or flash the latest version from this page again.
